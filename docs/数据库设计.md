# 数据库设计

## 当前状态

初始化阶段尚未引入数据库驱动、ORM 或迁移工具，也没有创建任何业务表。三个应用均可在没有数据库的情况下启动。本文件不列出未经实现的表结构，以免与代码产生误解。

## 后续维护约定

新增表时，同一轮补充以下内容，并记录对应迁移脚本：

- 表名、业务用途、与其他表的关系。
- 每个字段的名称、类型、是否可空、默认值和中文说明。
- 主键、唯一约束、索引及状态值含义。
- 删除、保留、脱敏和必要的并发控制约定。

预计需要保存任务、证据、审批与执行记录；具体表结构在实现相应功能时确定。图框架检查点与业务审计记录职责不同，长期经验记忆也不等同于检查点，不能仅凭框架表替代业务设计。
