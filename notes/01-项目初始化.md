# 项目初始化

## 本轮功能

- 创建独立 Phoenix 仓库与 Maven 多模块工程，不修改原智能客服项目。
- 创建三个可独立启动的 Spring Boot 骨架，默认使用 18080、18081、18082 端口，只监听本机。
- 添加健康检查、应用身份信息及目标应用探活接口。
- 控制端加入 LangChain4j 与 LangGraph4j 基础依赖，提供无真实模型请求的冒烟测试。
- 添加中文 README、架构说明、数据库维护入口、仓库开发规则和本轮记录。
- 添加可选 Redis Compose 定义，不自动启动容器，不连接已有 Redis。

## 新增类及作用

| 类 | 所在模块 | 作用 |
| --- | --- | --- |
| `PhoenixServerApplication` | `phoenix-server` | Agent 控制端启动入口 |
| `PhoenixMcpServerApplication` | `phoenix-mcp-server` | 目标机工具服务骨架入口，尚无 MCP 协议 |
| `PhoenixDemoApplication` | `demo` | 最小目标应用启动入口 |
| `DemoController` | `demo` | 提供不依赖外部组件的 `/api/demo/ping` |
| `PhoenixServerApplicationTests` | `phoenix-server` | 随机端口启动控制端并检查 HTTP 健康接口 |
| `FrameworkSmokeTests` | `phoenix-server` | 验证兼容模型客户端构建和最小图执行，不发送模型请求 |
| `PhoenixMcpServerApplicationTests` | `phoenix-mcp-server` | 验证工具服务启动，并明确 `/mcp` 尚不存在 |
| `PhoenixDemoApplicationTests` | `demo` | 验证目标应用健康与中文探活响应 |

本轮没有修改已有业务类，也没有数据库表变更。每个新增方法均提供简短中文 Javadoc。

## 配置和工程文件

父 `pom.xml` 统一 Java 与依赖版本，三个子模块各自产生可执行 JAR。`application.yml` 设置进程身份、独立端口、优雅停止和受限的 Actuator 暴露范围。`.gitignore` 排除环境配置、密钥、IDE 文件和构建产物；`.editorconfig` 和 `.gitattributes` 统一基础文本格式。

## 验证

- `mvn -B -ntp verify`：全部模块构建成功，共 7 项测试通过，失败、错误、跳过均为 0。
- `.\mvnw.cmd -B -ntp verify`：使用仓库提供的 Maven 3.9.14 Wrapper 再次完整构建，7 项测试全部通过。
- 测试在随机端口启动三个真实 HTTP 服务，验证健康状态；目标应用探活返回正常；工具服务 `/mcp` 返回 404，避免把骨架误认为可用协议服务。
- 框架测试只构建 OpenAI 兼容客户端并执行确定性最小图；没有发出真实模型请求，也没有验证跨进程恢复。
- 三个模块均生成 Spring Boot 可执行 JAR；未另外启动打包后的 JAR 做固定端口测试。
- `docker compose -f demo/compose.yaml config --quiet`：配置校验通过。本轮没有拉取镜像或启动 Redis，不能视为容器运行验证通过。
- Git 忽略检查确认环境文件、本地配置、日志与 `target/` 产物被排除；暂存后的空白检查通过。
